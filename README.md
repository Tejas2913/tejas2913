## Featured Projects

### TestGenAI: AI-Assisted Test Generation
*Jun 2026 – Aug 2026*

A developer tool that uses LLMs to generate Python unit tests and test oracles from source code and natural-language specifications. It aims to reduce the manual effort of writing tests; generated tests are meant to be reviewed, not trusted blindly.

- **Architecture:** a React interface for the end-to-end workflow, a FastAPI REST backend, and database integration for test history.
- **AI integration:** the backend supports multiple LLMs, with prompts designed around source-code and specification inputs.
- **Reliability:** structured output validation checks LLM responses so generated test cases stay consistent and usable.

`Python` `FastAPI` `React` `LLM Integration` `Prompt Engineering`

### FraudShield AI: ML-Based Fraud Risk Detection
*Feb 2026*

A full-stack fraud risk detection application, built and deployed independently. It connects an ML classification pipeline to a secured API and a review interface.

- **ML pipeline:** TF-IDF features with a Logistic Regression and SVM voting ensemble for NLP classification.
- **Backend:** a FastAPI service exposing JWT-secured REST APIs.
- **Frontend:** a React dashboard for risk scoring and result review.
- **Reported results:** 97% accuracy, 95% recall, and 94% F1 from the project's own evaluation. These are experimental results and do not imply the same performance on other datasets or in other fraud scenarios.

`Python` `FastAPI` `Scikit-learn` `TF-IDF` `React` `JWT` `Vercel` `Render`

### GyanSetu: AI Math Assessment Platform
*Jun 2026*

A full-stack mathematics assessment platform that grades both typed and handwritten answers.

- **Multimodal grading:** Gemini Vision and Gemini 2.5 Flash evaluate answers with rubric-based, step-wise grading and partial-mark scoring.
- **Data and access control:** Supabase PostgreSQL with row-level security.
- **Dashboards:** role-based Student, Teacher, and Parent views, with weak-topic analytics and automated report generation.
- **Stack:** React frontend and FastAPI backend.

`React` `FastAPI` `Supabase` `PostgreSQL` `Gemini`

### Retail Shelf Analytics

A computer vision project exploring AI-based analysis of retail shelves, covering product availability, price-tag detection, and OCR-based text extraction for shelf compliance checks.

`Python` `Computer Vision` `OCR`

### ECG Anomaly Detection

An anomaly detection project on ECG data using a Dense Autoencoder, with emphasis on model design and evaluation. Previously reported experimental results were **72% balanced accuracy** and **0.817 ROC-AUC**. This is an experimental ML project; it is not clinically validated and is not a diagnostic tool.

`Python` `Autoencoder` `Anomaly Detection`

### Urban Heat Island Mapping: GeoAI Research
*Ongoing research*

*Urban Heat Island Mapping and Mitigation through Satellite Data and Agent-Based Green Planting Strategies.* The research investigates scalable urban heat island prediction and mapping using geospatial data and machine learning.

- **Data and models:** Landsat 8/9 data processed with Google Earth Engine; Random Forest and XGBoost models with spatial cross-validation.
- **Interpretation:** SHAP-based explanations and hotspot mapping.
- **Finding so far:** direct model transfer from Bangalore to Delhi did not generalize well, motivating city-specific models and feature-transferability analysis.

`Google Earth Engine` `Landsat` `Random Forest` `XGBoost` `SHAP`
